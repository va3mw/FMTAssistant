Days before

Software

  • Latest FMT Assistant downloaded and opened once.
  • Schedule checked against the ARRL FMT page (fmt.arrl.org) and the fmt-nuts group; any change entered in Setup & radio.
  • WSJT-X Settings > Frequencies: calibration intercept 0 and slope 0 ppm. FMT Assistant applies the correction itself.
  • WSJT-X FreqCal frequency list has the WWV/CHU frequencies you can hear.
  • Setup & radio: WSJT-X log folder chosen (WSJT-X File > Open log directory); the WSJT-X panel shows no errors.
  • Voice prompts tested (Test button), volume set.
  • Windows clock synchronised (Settings > Time > Sync now).
  • FlexRadio users (optional): radio found, slice chosen, Set radio tested.

Rehearse

  • At least one full practice run on the Practice tab (a local AM station or WWV).
  • Practice includes: delete the old fmt.all, set the dial, centre the tone near 1500 Hz, type the exact dial, measure, Capture, read the answer.
  • Readings steady: SD a few tenths of a hertz.

Audio recording (recommended)

  • A separate recorder is set up to record the receiver audio for the whole evening, for example Audacity recording the same input WSJT-X uses (DAX on a Flex).
  • Test recording made and played back.
WSJT-X won't record it for you. In FreqCal mode WSJT-X writes only fmt.all; it does not save .wav files, even with Save > Save all on. Use another program if you want the audio.

On the night, before 02:09 UTC

  • Radio on and warmed up (an hour or more is best); don't change radio settings from here to the end.
  • WSJT-X and FMT Assistant open; Test night tab showing; voice on.
  • Problems pill reads No problems (or each one understood).
  • Old fmt.all deleted (WSJT-X File > Open log directory), so earlier readings can't mix in.
  • Audio recorder started, with enough disk space for about 90 minutes.
  • Receive mode USB (DIGU on a Flex), RIT off, no DIGU offset.
  • Pen and this sheet ready to write each dial down as a backup.
  • Phone or other noise sources away from the radio.
Every Capture copies fmt.all into the session folder and also saves a dated copy in the session's Archive folder, for example Archive\20261113-023612Z_2_run1_W8RKO40m.all. Archive copies are never overwritten, so every file processed on the night is kept. Open session folder on the Results tab shows them.

Times are the November 13, 2026 schedule built into FMT Assistant. Confirm them on the ARRL FMT page before the night. Nominal frequencies are approximate: listen to each call-up and use Tone is at… if the tone isn't near 1500 Hz.
